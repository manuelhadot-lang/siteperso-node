TP1 — LED sur ESP32 (schéma KiCad)
6. Programme à téléverser
  // TP1 - Blink LED D1 sur GPIO0 (schéma KiCad Veilleur Intelligent)
  const int PIN_LED = 0;   // GPIO18 -> R3 -> D1
  
  void setup() {
    pinMode(PIN_LED, OUTPUT);
    Serial.begin(115200);
    Serial.println("TP1 pret - LED sur GPIO0");
  }
  
  void loop() {
    // LED allumee quand GPIO0 = LOW (montage KiCad)
    digitalWrite(PIN_LED, LOW);
    Serial.println("LED ON");
    delay(500);
  
    digitalWrite(PIN_LED, HIGH);
    Serial.println("LED OFF");
    delay(500);
  }

8. À retenir
• Sur cette carte Low Power, il n'y a pas de LED utilisateur : on utilise D1 externe.
• GPIO18 sert ici de sortie pour la LED (repère du schéma KiCad).
• L'ESP32 travaille en 3,3 V : ne pas appliquer 5 V sur un GPIO.

TP2 — Mesurer la luminosité avec une LDR
Projet : Veilleur de nuit intelligent  |  1ère STI2D  |  Durée : 4 h  |  Support : schéma KiCad « Veilleur
Intelligent »
1. Objectif
Réaliser le pont diviseur photorésistance du schéma KiCad (R1 + R2), mesurer la tension au multimètre,
puis lire la valeur numérique avec l'ADC (Analog To Digital Converter) de l'ESP32.
2. Matériel (repères du schéma KiCad)
Repère Composant Rôle
U1 uPesy ESP32 Low Power Traitement + ADC 12 bits
R1 LDR03 (photorésistance) Capteur de luminosité
R2 Résistance 10 kΩ Pont diviseur avec R1
— Multimètre Mesure de tension
— Fils + plaquette Montage
3. Câblage d'après le schéma KiCad
Le schéma KiCad prévoit un pont diviseur entre +3,3 V et GND : R1 (LDR) côté +3,3 V, R2 (10 kΩ) côté
GND. Le point milieu (jonction R1–R2) est la tension à mesurer.
• R1 (LDR) entre +3,3 V (broche 3V3 de U1) et le point milieu.
• R2 (10 kΩ) entre le point milieu et GND.
• Point milieu → GPIO22 de U1 (entrée analogique seule, adaptée à l'ADC).
• Masse commune : GND de la carte et du pont.
Note
GPIO22 est une entrée seule (pas de sortie). Ne pas utiliser GPIO22 (mesure batterie sur la carte Low Power). Tout le
pont doit être alimenté en 3,3 V, jamais en 5 V. La tension V22 se trouve aux bornes de R2

  // TP2 - Lecture LDR (R1) via pont avec R2 - GPIO22 (schema KiCad)
  const int PIN_LDR = 22 ;
  
  void setup() {
    Serial.begin(115200);
    Serial.println("TP2 pret - lecture GPIO22");
  }
  
  void loop() {
    int brut = analogRead(PIN_LDR);           // 0 .. 4095
    float tension = (brut / 4095.0) * 3.3;    // estimation en volts
  
    Serial.print("ADC=");
    Serial.print(brut);
    Serial.print("   U22=");
    Serial.print(tension, 2);
    Serial.println(" V");
    delay(300);
  }
