CD4511 — Décodeur BCD / 7 segments

            

                

                    Le CD4511 (ou équivalent CMOS) convertit un code BCD 4 bits
                    (A = LSB) en sorties pour un afficheur 7 segments en cathode commune.
                    Il intègre une mémorisation (broche LE) et les fonctions
                    extinction (BI) et test lampe (LT).
                

                
Broches du symbole (simulateur)

                

                    
                        
BrocheRôleNiveau actif

                    
                    
                        
A, B, C, DEntrées BCD (A = bit faible)1 = logique haut (0…VCC)

                        
LEVerrouillage — 0 : suivi des entrées ; 1 : mémoriseRelier à 0 V pour suivre un compteur

                        
BIExtinction de l’affichage0 V = éteint — relier BI au +5 V

                        
LTTest lampe (tous segments ON)0 V = test — relier LT au +5 V en usage normal

                        
a … gSorties vers les segments1 = segment allumé (cathode commune)

Câblage typique

                
    
                    
  • Relier a … g aux entrées du composant Afficheur 7 segments (SEG_1).
    • 
                    
  • Relier la cathode commune (COM) de l’afficheur à la masse (GND_1).
    • 
                    
  • BI et LT au +5 V (VCC_1 ou LOGIC_1 à 1) — pas à la masse.
    • 
                    
  • LE à 0 V (GND_1 ou borne à 0) pour suivre un compteur.
    • 
                

                
Simulation

                

                    Modèle XSPICE : bascules d_dlatch, table d_genlut,
                    ponts analogiques/numériques. Nécessite digital.cm et ngspice avec XSPICE
                    (npm run check-ngspice).

74HC90 — Compteur décade asynchrone

            

                

                    Le 74HC90 (ou 74LS90) est un compteur asynchrone
                    en deux sections : ÷2 (bascule A, horloge CP0) et
                    ÷5 (bascules B–D). En mode décade, la sortie
                    Q0 est reliée à CP1 pour former un compteur
                    0…9 sur les sorties Q0–Q3 (code binaire naturel).
                

                
Brochage réel (boîtier DIP 14 — 74HC90)

                

                    
                        
Broche DIPSymboleRôle

1CP1Horloge section ÷5 — relier à Q0 (décade)

                        
12Q0Sortie LSB — vers CD4511_1 entrée A

                        
9Q1Vers entrée B

                        
8Q2Vers entrée C

                        
11Q3MSB — vers entrée D

                        
2, 3MR1, MR2Reset (niveau haut = compteur à 0)

                        
6, 7MS1, MS2Mode — laisser à 0 V (décade)

Sur le schéma, Q0…Q3 sont alignés verticalement (comme A…D du CD4511) pour des fils horizontaux courts.

Câblage typique (mode décade 0…9)

                
    
                    
  • Les composants sont numérotés HC90_1, CD4511_1, SEG_1, GND_1, VCC_1, GImp_1, etc.
    • 
                    
  • Horloge 1 Hz sur GImp_1 → CP0 pour une seconde par pas (préréglage « tick seconde » dans le panneau GImp).
    • 
                    
  • Le fil Q0 → CP1 reste recommandé sur la plaquette ; il est aussi appliqué automatiquement en simulation.
    • 
                

                
Deux chiffres (unités + dizaines)

                
    
                    
  • Dupliquer la chaîne HC90 → CD4511 → SEG (HC90_2, CD4511_2, SEG_2).
    • 
                    
  • Horloge GImp_1 uniquement sur HC90_1 CP0 ; HC90_2 CP0 via une porte ET.
    • 
                    
  • Report au chiffre 9 : relier HC90_1 Q0 et Q3 aux entrées de l’ET, sortie → HC90_2 CP0. Au comptage 9 (binaire 1001), Q0 et Q3 sont à 1 → un front horloge sur les dizaines.
    • 
                    
  • Ne pas utiliser Q1 + Q3 : en BCD 0…9 ces sorties ne sont jamais hautes en même temps (seul l’état invalide 10 = 1010 les active).
    • 
                    
  • HC90_2 : même câblage décade (Q0 → CP1, MR/MS à 0, VCC/GND).
    • 
                    
  • Affichage 0…99 : si le report est correct (AND Q0+Q3 ou Q3), l’animation utilise un comptage idéal en temps réel (1 impulsion = +1), fiable à toute fréquence du GImp.
    • 
                

                
Simulation

                

                    Quatre bascules D en mode bascule (D relié à /Q, horloges en cascade).
                    Modèle XSPICE (d_dff) si ngspice et digital.cm sont disponibles ;
                    sinon repli sur sources comportementales (comme la bascule D du simulateur).
                    Vérification : node Simulateur/Engine/ic74hc90-decade.test.mjs,
                    node Simulateur/Engine/hc90-cascade.test.mjs ou
                    npm run check-ngspice.
                

                
Double-clic sur le symbole pour rouvrir cette fiche.

Arduino UNO R3

            

                

                    Carte Arduino UNO R3 (ATmega328P) : alimentation 5 V / 3,3 V,
                    14 broches digitales D0–D13 et 6 entrées analogiques A0–A5.
                    L’éditeur de sketch est dans le panneau à droite (ouvert à la pose du composant).
                

                
Broches du symbole (simulateur)

                

                    
                        
BrocheRôle

                    
                    
                        
5V, 3V3Alimentation sortie (rails simulés)

                        
GND, GND2Masse

                        
VINAlimentation externe (entrée)

                        
RESETReset (pull-up interne modélisé)

                        
A0 … A5Entrées analogiques / I²C (A4/A5)

                        
D0, D1UART (RX/TX)

                        
D2 … D13GPIO digitales (PWM : D3, D5, D6, D9, D10, D11)

                        
D13LED intégrée (LED_BUILTIN = 13)

                    
                

                
Registres AVR — ports et broches (ATmega328P)

                

                    Chaque broche GPIO est pilotée par un couple DDRx (direction) et
                    PORTx (niveau ou pull-up). Le simulateur interprète
                    pinMode / digitalWrite et les accès directs aux registres
                    (DDRD |= (1<<5), PORTB = 0xFF, etc.).
                    Pendant la simulation, les valeurs hex des registres s’affichent sur le symbole UNO.
                

                

                    
                        
Port AVRRegistresBitsBroches ArduinoRepères MCU

                    
                    
                        

                            Port D
                            DDRD / PORTD
                            0 … 7
                            D0 … D7
                            PD0 … PD7
                        

                        

                            Port B
                            DDRB / PORTB
                            0 … 5
                            D8 … D13
                            PB0 … PB5 (LED_BUILTIN = PB5 / D13)
                        

                        

                            Port C
                            DDRC / PORTC
                            0 … 5
                            A0 … A5
                            PC0 … PC5 (pins Arduino 14 … 19 en mode digital)
                        

                    
                

                
Correspondance broche ↔ bit (référence rapide)

                

                    
                        
BrochePort / bitNuméro ArduinoUsage courant

                    
                    
                        
D0PORTD bit 00UART RX

                        
D1PORTD bit 11UART TX

                        
D2 … D7PORTD bits 2 … 72 … 7GPIO (PWM : D3, D5, D6)

                        
D8 … D12PORTB bits 0 … 48 … 12GPIO (PWM : D9, D10, D11)

                        
D13PORTB bit 513GPIO, LED intégrée

                        
A0 … A3PORTC bits 0 … 314 … 17Analogique / GPIO digital

                        
A4PORTC bit 418I²C SDA (SDA)

                        
A5PORTC bit 519I²C SCL (SCL)

                    
                

                

                    DDRx : bit à 1 = sortie, à 0 = entrée.
                    PORTx en sortie : bit à 1 = HIGH (5 V), à 0 = LOW.
                    En entrée avec pinMode(n, INPUT_PULLUP) : bit PORT à 1 active le pull-up interne.
                

                
CD4511 + PORTD (4 bits faibles)

                

                    Pour afficher le chiffre 0…9 avec PORTD = n, reliez
                    A→D0, B→D1, C→D2, D→D3, puis :
                

                
void setup() {
  DDRD = 0b00001111;  // D0…D3 en sortie
}
void loop() {
  PORTD = 6;          // affiche 6
}

                

                    Attention : écrire DDRD = 6 dans loop() (au lieu de
                    PORTD) reconfigure les directions et peut bloquer l’affichage.
                    Seul PORTD fixe les niveaux logiques.
                

                
Programmation

                
    
                    
  • Éditeur à droite : sketch .ino + bouton Compiler (arduino-cli).
    • 
                    
  • Carte cible : arduino:avr:uno.
    • 
                    
  • À la simulation, le moteur interprète pinMode(…, OUTPUT|INPUT|INPUT_PULLUP), digitalWrite, delay(ms) et les écritures DDRx / PORTx pour piloter D0–D13 et A0–A5.
    • 
                    
  • Reliez GND de l’UNO à la masse du circuit si vous utilisez les rails 5 V / 3,3 V.
    •

Commandes de l'Éditeur

            

                
Ctrl + C / Ctrl + V : Copier / Coller la sélection (Évite le double-copier)

                
Clic simple (Simulation active) : Commuter l'état (0 ou 1) d'une Borne Logique

                
Clic simple (Hors simulation) : Sélectionner un fil ou un composant

                
Double-clic : Modifier la valeur (R, C, L, VCC…) ; fiche technique CD4511, 74HC90, Arduino UNO

                
[Shift] + Glisser cadre : Sélectionner plusieurs composants

                
[R] : Pivoter les composants sélectionnés de 90° (sauf bascules et GImp)

                
[X] : Retourner horizontalement le GImp sélectionné

                
[Suppr] ou [Backspace] : Supprimer la sélection (Composants ou fil choisi)

                
[Espace] : Ajouter un point d'ancrage intermédiaire sur un fil en cours de tracé

                
[Ctrl] + [Z] / [Ctrl] + [Y] : Annuler / Rétablir
