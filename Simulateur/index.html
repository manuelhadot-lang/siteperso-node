Mesures tensions, courants et résistances (V, A, Ω) —

⌨️ Commandes

  • Glisser la vue (grille vide) ou un composant sélectionné
  • Molette pour zoom
  • R rotation (résistance, voltmètre, ampèremètre, ohmmètre) : horizontal ↔ vertical
  • Suppr suppression des composants et fils sélectionnés ; clic sur un tronçon de fil puis Suppr pour retirer ce fil ; Maj+cliquer-glisser sur la grille pour encadrer une zone (ajout à la sélection), puis Suppr pour tout supprimer dans l’encadré
  • Ctrl+C copier le composant (résistance / voltmètre / ampèremètre / ohmmètre : orientation ; alimentation : type)
  • Ctrl+V coller sous le dernier curseur sur la grille
  • Ctrl+Z annuler — Ctrl+Y ou Ctrl+Maj+Z refaire
  • Fichier : projet JSON (composants, fils, nœuds) ; hébergé sur Render ou en fichier statique, l’enregistrement passe par le dossier Téléchargements ou la boîte du navigateur (Chrome / Edge : fichier sur disque avec handle).
  • Fils : depuis une jonction rouge (composant ou extrémité de fil), cliquer–glisser (orthogonal, suit le curseur) ; Espace inverse le sens du coude ; relâcher sur une autre jonction pour terminer ; relâcher sur la grille fige un tronçon et place une jonction au bout ; reprendre depuis cette jonction pour continuer jusqu’à un composant — suppression : clic sur un tronçon (surbrillance orange) puis Suppr ; Maj+encadrer sur la grille ajoute composants et fils touchés à la sélection
  • Simulation DC (ngspice) : bandeau en bas — Simuler lance le calcul ; Vérification ou Fichier → Vérification simulation ouvre le détail (alertes, netliste, journal). L’ohmmètre mesure la résistance équivalente entre ses bornes (réseau passif) sans pile sur le schéma.
  • Résistance / alimentation : cliquer sur la valeur affichée sous le symbole (Ω ou tension en V) pour la modifier — le glisser-déplacement part du reste du composant

🔍 Vérification simulation

Lancez une simulation avec le bouton « Simuler » du bandeau inférieur, puis ouvrez cette fenêtre pour voir le détail (mesures, alertes, netliste, journal).
