CD4511 — Décodeur BCD / 7 segments

Le CD4511 (ou équivalent CMOS) convertit un code BCD 4 bits (A = LSB) en sorties pour un afficheur 7 segments en cathode commune. Il intègre une mémorisation (broche LE) et les fonctions extinction (BI) et test lampe (LT).

Broches du symbole (simulateur)

BrocheRôleNiveau actif
A, B, C, DEntrées BCD (A = bit faible)1 = logique haut (0…VCC)
LEVerrouillage — 0 : suivi des entrées ; 1 : mémorise—
BIExtinction de l’affichage0 = segments éteints
LTTest lampe (tous segments ON)0 = test actif
a … gSorties vers les segments1 = segment allumé (cathode commune)

Câblage typique

  • Relier a … g aux entrées du composant Afficheur 7 segments.
  • Relier la cathode commune (COM) de l’afficheur à la masse.
  • Alimenter les entrées BCD via des Bornes numériques, un VCC ou des portes logiques (0 V / 5 V).
  • Laisser BI et LT au niveau haut (5 V) si non utilisés.

Simulation

Modèle XSPICE : bascules d_dlatch, table d_genlut, ponts analogiques/numériques. Nécessite digital.cm et ngspice avec XSPICE (npm run check-ngspice).

Double-clic sur le symbole pour rouvrir cette fiche.

Commandes de l'Éditeur

Ctrl + C / Ctrl + V : Copier / Coller la sélection (Évite le double-copier)

Clic simple (Simulation active) : Commuter l'état (0 ou 1) d'une Borne Logique

Clic simple (Hors simulation) : Sélectionner un fil ou un composant

Double-clic : Modifier la valeur (Résistances, VCC, Niveau Haut de Borne Logique)

[Shift] + Glisser cadre : Sélectionner plusieurs composants

[R] : Pivoter les composants sélectionnés de 90° (sauf bascules et GImp)

[X] : Retourner horizontalement le GImp sélectionné

[Suppr] ou [Backspace] : Supprimer la sélection (Composants ou fil choisi)

[Espace] : Ajouter un point d'ancrage intermédiaire sur un fil en cours de tracé

[Ctrl] + [Z] / [Ctrl] + [Y] : Annuler / Rétablir
