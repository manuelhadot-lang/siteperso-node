⌨️ Commandes

  • Glisser la vue (grille vide) ou un composant sélectionné
  • Molette pour zoom
  • R rotation (résistance, voltmètre) : horizontal ↔ vertical
  • Suppr suppression du composant sélectionné
  • Ctrl+C copier le composant (résistance / voltmètre : orientation ; alimentation : type)
  • Ctrl+V coller sous le dernier curseur sur la grille
  • Ctrl+Z annuler — Ctrl+Y ou Ctrl+Maj+Z refaire
  • Fichier : projet JSON (composants, fils, nœuds) ; hébergé sur Render ou en fichier statique, l’enregistrement passe par le dossier Téléchargements ou la boîte du navigateur (Chrome / Edge : fichier sur disque avec handle).
  • Fils : depuis une jonction rouge (composant ou extrémité de fil), cliquer–glisser (orthogonal, suit le curseur) ; Espace inverse le sens du coude ; relâcher sur une autre jonction pour terminer ; relâcher sur la grille fige un tronçon et place une jonction au bout ; reprendre depuis cette jonction pour continuer jusqu’à un composant
