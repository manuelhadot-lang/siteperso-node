# Textures CC0 (lab 3D)

Packs **libre de droits (CC0)** pour le lab.

## Sources

- [AmbientCG](https://ambientcg.com/) — matériaux PBR (Color / Normal / Roughness / AO…)
- [Poly Haven](https://polyhaven.com/) — HDRI

Aucune attribution obligatoire (CC0), mais citer les auteurs est apprécié.

## Télécharger / mettre à jour

```powershell
powershell -ExecutionPolicy Bypass -File texture/download-packs.ps1
```

Les fichiers déjà présents sont ignorés (`*_color.jpg` ou HDRI existants).

## Dossiers

| Dossier | Contenu |
|---------|---------|
| `herbe` | herbe, sol végétal |
| `pierre` | roches |
| `pave` | pavés |
| `bois` | bois, parquet, écorce |
| `brique` | briques, façades |
| `tuiles` | carrelage / tuiles |
| `beton` | béton |
| `bitume` | asphalte |
| `metal` | métaux |
| `tissus` | tissus, cuir |
| `neige` | neige |
| `sable` | sable |
| `sol` | sols / graviers |
| `hdri` | environnements HDR |
| `decalcomanie` | plâtre peint, graffiti |

Formats : JPG 1K pour les maps, HDR 1K pour les HDRI (sauf fichiers déjà plus lourds déjà présents).
